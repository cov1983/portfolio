PROJECT DISCOVERY FORM

Open index.html in your browser to use the mockup. No installation or build step is required.

All source code is in index.html:
- CSS inside the <style> element controls the appearance.
- HTML defines the page layout.
- JavaScript inside the <script> element defines the questions and interactions.
- Edit the sections array to change the questionnaire.

Includes seven sections, required-answer validation, browser-local draft storage, answer review, and a downloadable text brief.

This is a local prototype. It does not submit answers to a server or send email. Browser draft storage may vary when opening the file directly.
